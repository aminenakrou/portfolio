Case Study / 02

Scoring deCrédit

Projet statistique autour du risque crédit, du déséquilibre de classes, de SMOTE et de l'évaluation par courbe ROC.

GitHub Live Demo Retour au portfolio
01. Contexte / problème
Évaluer le risque client avant l'accord d'un crédit.
02. Dataset
Données financières avec déséquilibre de classes indiqué dans le contenu existant.
03. Analyse exploratoire
A completer avec les graphiques et constats du rapport RMarkdown.
04. Méthodologie
Comparaison de modèles, rééquilibrage SMOTE et évaluation par courbe ROC.
05. Modeles
Régression logistique, arbre de décision et forêt aléatoire selon le contenu existant.
06. Résultats
Résultats présentés dans le rapport interactif. Aucune métrique nouvelle n'est inventée.
07. Visualisations
Courbe ROC et elements du rapport RMarkdown.
08. Architecture / déploiement
Rapport interactif publié via GitHub Pages.
09. Technologies
R, RMarkdown, régression logistique, Random Forest, SMOTE, ROC.
10. Ce que j'ai appris
À compléter avec ton retour personnel exact.
