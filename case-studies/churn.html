Case Study / 01

Customer ChurnPrediction

Pipeline ML end-to-end pour prédire l'attrition client, avec données déséquilibrées, comparaison de modèles, dashboard Streamlit, API Flask, Docker et MLflow.

GitHub Live Demo Retour au portfolio
01. Contexte / problème
Prédire l'attrition client et rendre le résultat exploitable dans une interface.
02. Dataset
Données client déséquilibrées. Le détail exact du dataset devra être documenté depuis le dépôt projet.
03. Analyse exploratoire
Information a completer avec les visualisations et constats verifies du projet.
04. Méthodologie
Feature engineering, comparaison de modèles et suivi d'expériences.
05. Modeles
Random Forest et XGBoost selon le contenu existant.
06. Résultats
AUC 0.91 indiquée dans le portfolio existant. Aucune métrique supplémentaire n'est ajoutée.
07. Visualisations
Dashboard Streamlit mentionne dans le projet.
08. Architecture / déploiement
API Flask containerisée avec Docker et suivi MLflow.
09. Technologies
Python, XGBoost, Random Forest, Streamlit, Flask, Docker, MLflow.
